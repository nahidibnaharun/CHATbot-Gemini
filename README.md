# 💬 CHATbot Gemini

An interactive AI-powered chatbot built with **Node.js**, **JavaScript**, and **HTML/CSS**.  
This bot responds in real-time based on user input with a clean frontend and basic backend logic.

---

## 🌐 Live Demo  
🚧 *(Currently not hosted)* — you can run it locally (instructions below)  

---


## ⚙️ Features

- 🧠 Simple chatbot logic with keyword-based response
- 🖼️ Clean frontend with HTML/CSS styling
- 🔄 Real-time interaction via JavaScript
- 🌐 Node.js-based backend (basic routing)

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/nahidibnaharun/CHATbot-Gemini.git
cd CHATbot-Gemini

# Install dependencies
npm install

# Run the server
node server.js
Visit http://localhost:3000 in your browser to use the chatbot.
